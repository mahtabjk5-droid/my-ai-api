# Security Policy

## Supported versions

This project is currently maintained as a starter/learning project. Please report any security issue privately.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, contact the repository maintainer privately and provide:

- a clear description of the issue
- affected files or endpoints
- steps to reproduce
- potential impact

## Best practices

- Do not commit `.env` files or live API keys.
- Rotate credentials if they are exposed.
- Review dependency updates regularly.
